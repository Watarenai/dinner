# 要件定義書: 食材スロット

## 1. プロダクトビジョン

「今日の夕飯、何にしよう？」を楽しく解決する。スロットマシンの演出で食材をランダム選出し、献立のヒントを提供するWebアプリ。

## 2. ターゲットユーザー

- 毎日の夕飯の献立に悩む人
- 手軽にブラウザで使いたい人（インストール不要）

## 3. MVP機能要件

### 3.1 MVP機能一覧

| ID | 機能 | 状態 |
|---|---|---|
| F-001 | 野菜リール3つ＋肉リール1つで計4リールのスロット | 実装済み |
| F-002 | 各リールの個別ストップボタン | 実装済み |
| F-003 | 一斉ストップボタン | 実装済み |
| F-004 | リセット（再スピン）ボタン | 実装済み |
| F-005 | 全リール停止後に選ばれた食材を表示 | 実装済み |
| F-006 | スロット回転中の効果音 | 実装済み |
| F-007 | リールごとにランダムな回転速度 | 実装済み |
| F-008 | スマホ対応（レスポンシブ） | 実装済み |
| F-009 | 食材カテゴリの視覚的区別（野菜=緑、肉=赤） | 実装済み |
| F-010 | スロット停止時の演出強化（CSS transition） | 実装済み |

## 4. 非機能要件

| ID | 要件 | 説明 |
|---|---|---|
| NF-001 | パフォーマンス | ページ読み込み後即座に操作可能であること |
| NF-002 | デプロイ | GitHub Pagesで静的配信。ビルド不要 |
| NF-003 | ブラウザ対応 | モダンブラウザ（Chrome, Safari, Firefox）最新版 |

## 5. MVPスコープ外（将来検討）

以下はMVPには含めず、将来のフェーズで検討する:

- 食材の追加・削除のUI（設定画面）
- 過去の結果の履歴保存（localStorage）
- レシピ提案機能（外部API連携）
- PWA化（オフライン対応）
- 調味料リールの追加
- ユーザーごとの好み設定

## 6. 食材データ仕様

### 野菜（19品目）
だいこん, にんじん, じゃがいも, たまねぎ, キャベツ, レタス, ほうれんそう, こまつな, なす, きゅうり, トマト, ピーマン, さつまいも, ねぎ, しそ, ごぼう, とうもろこし, かぼちゃ, ブロッコリー

### 肉（3品目）
牛肉, 鶏肉, 豚肉

## 7. UI仕様

- リールアイテムサイズ: 100×100px / スマホ時80×80px（CSS・JSのスナップ処理に紐づく定数）
- カテゴリ色: 野菜=緑（#66bb6a）、肉=赤（#ef5350）
- 各リール直下にストップボタン配置、一斉ストップ・リセットは別行
- 結果表示: 「🍽️ 選ばれた食材: ○○、○○、○○、○○」
- ダーク背景（#1a1a2e）のUI
